## Read this first (harness notes from round 3)

| Topic | What to do |
|-------|------------|
| **Preview padlock** | New tabs start **unlocked**, but the lock is stored per tab in the session, so a fixture path you opened locked in an earlier run comes back locked. For every row, state the padlock position and crop it into one screenshot. Rows say which position they need. |
| **Counting arrow presses** | A press moves one **visual row** inside a multi-row paragraph and one **block** otherwise. Do not grade by press count. Grade by the `Rendered arrow nav` log lines (one per block-to-block move) and by where the typed character lands. |
| **Caret in screenshots** | The caret blinks. A screenshot without a caret is not evidence that it did not move; the log line and the status bar `Ln` are. |
| **Code blocks** | Clicking code text gives no caret. Click the block's **Edit** button first, then click in the text. |
| **Saving inside an undo row** | Do not press Ctrl+S between typing and Ctrl+Z (round 3 UND-3 attempt 1). |
| **T1-19 line number** | The `x` lands on line **42** (`    return value`); line 43 is the closing fence. The round-3 gate said 43. |
