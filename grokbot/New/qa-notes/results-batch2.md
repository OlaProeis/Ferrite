### Common root cause of all hangs (T1-2, T1-7, T1-17, T1-18, T1-18b)
All six gdb dumps show the main thread blocked in parking_lot::raw_rwlock::RawRwLock::lock_shared_slow <- ferrite::markdown::editor::arrow_nav_sel_key <- remember_arrow_nav_sel <- render_paragraph / render_session_plain_text_block <- MarkdownEditor::show_rendered_editor. Apparent re-entrant shared-lock self-deadlock in rendered arrow-nav tracking.
