## Verdict

**Not ready to tag yet.** The feature set is essentially complete and the automated suite is green (1,920 tests passed, 0 failed; clippy clean apart from known dead-code warnings), but the review found **7 release blockers** — all silent data-loss or crash paths reachable from ordinary user actions — plus a set of should-fix bugs and out-of-date docs. Fix the blockers, then run the manual checklist.

> **Status update (same day):** all 7 release blockers below are **FIXED** with regression tests (suite now 1,930 passed / 0 failed). B1 also fixed the UTF-16 EOL misdetection on the reload path; B2 also gated reload for image/PDF viewer tabs; B5 also fixed a latent bug where line-1 blocks resolved to the Document root node (whole-file span) in the flush path; B6 also shifts carets on block-indented lines so mixed-selection Tab lands correctly. High/medium/low items below are still open unless noted.

## High priority (should fix, or explicitly defer)

1. **CRLF gap — video embed resize (#174):** `rewrite_video_embed_dimensions` still rebuilds the buffer with `lines()`+`join("\n")` — dragging a video handle converts the whole CRLF file to LF and dirties every line. `src/markdown/video_embed.rs:187-213`. (Same forbidden pattern also in TOC insert: `src/markdown/toc.rs:199` `generate_toc` joins with `\n`, creating mixed EOLs when inserted into CRLF docs.)
2. **CRLF gap — Enter in raw editor (#174):** Enter inserts a bare `\n` regardless of `tab.line_ending`; every Enter in a CRLF file manufactures mixed line endings. `src/editor/ferrite/editor.rs:2857`. FerriteEditor needs a line-ending setting analogous to `set_tab_settings`.
3. **CRLF gap — UTF-16 EOL detection (#174):** `LineEnding::detect_from_bytes` runs on raw pre-decode bytes; UTF-16LE CRLF (`0D 00 0A 00`) is detected as LF, so subsequent rewrites flip the document's EOLs. Should use `detect_from_content(&content)` post-decode. `src/state.rs:1773, ~2170, ~2320`.
4. **Image paste focus/hotkey (#164):** paste fires with no check that the editor has keyboard focus (fires while typing in Find, quick open, rename, settings) and doesn't exclude Shift — hijacks Ctrl+Shift+V. `src/app/input_handling.rs:405-434`.
5. **macOS emoji font (#168):** `load_system_font` skips `validate_font_bytes`; Apple Color Emoji is a TTC the project's own validator rejects, and being bitmap-only (sbix) likely renders **blank** glyphs; the ~180 MB file is re-read on every font-definitions rebuild; the `catch_unwind` guards a no-panic struct copy. Verify on macOS hardware before shipping that build. `src/fonts.rs:788-860`.
6. **Non-Windows title-bar drag (#153):** the fallback sends `Maximized(false)` + `OuterPosition` + `StartDrag` in one frame — the exact async un-maximize race #153 fixed on Windows. Defer `StartDrag` one frame. `src/app/title_bar.rs:262-283`.
7. **Split view scroll metrics (#175):** the new persistence block writes the **preview** pane's `scroll_offset`/`content_height`/`viewport_height` over the raw editor's values every frame — session persistence saves the wrong offset and the raw pane can jump after a content resync. Persist only `rendered_line_mappings` / dedicated preview fields. `src/app/central_panel.rs:2283-2285`.
8. **Mermaid autonumber badge (#165):** badge is painted at the same midpoint as the message label, which draws on top — numbers are obscured on nearly every message. Mermaid.js puts the number at the arrow start. `src/markdown/mermaid/sequence.rs:913, 984`.
9. **Mermaid forward-edge lanes (#165):** lane offsets are unclamped (±45 px on the dense fixture) and grouped too coarsely — arrows can visibly detach from nodes. `src/markdown/mermaid/flowchart/render/edges.rs:31-79, 676-680`.
10. **Mermaid sequence fit scale (#165):** fit scale computed from `EstimatedTextMeasurer` but painted with `EguiTextMeasurer` — CJK labels over-shrink the diagram (blank right margin) or overflow. `src/markdown/mermaid/mod.rs:251-253`.
11. **Reload wrong-tab risk (#149):** the confirm dialog captures a tab strip **index**, not an id; closing/reordering tabs while the dialog is open reloads (and wipes edits in) whichever tab now sits at that index. `src/state.rs:5068`.

## Medium (fix or consciously defer)

- **Reload UX (#149):** contradictory "Reload failed" + "Reloaded: file" toasts on failure (`src/app/dialogs.rs` both branches); error message double-wrapped as "Reload failed: Reload failed: …" (`src/state.rs:6516`); reload not blocked for image/PDF viewer tabs (`src/app/file_ops.rs:445-449`); Ctrl+Shift+R fires while the integrated terminal has focus (`src/app/keyboard.rs:60` — `CloseTab` is gated, Reload isn't).
- **Image paste (#164):** 1-second filename resolution + key-repeat means same-second pastes silently overwrite PNGs (`src/app/file_ops.rs:1572-1613`; same class in the widget context-menu paste, which also falls back to `0-clipboard.png` forever); pasting into an unsaved document writes `assets/` into the process CWD (Program Files → error toast; links break on save-as) (`src/path_utils.rs:255-270`).
- **Tab indent edge cases (#177):** overlapping cursors double-indent/outdent the shared line; Shift+Tab is a silent no-op on opposite-style leading whitespace (tab char in spaces mode and vice versa); block indent inserts whitespace on empty lines and includes the last line when the selection ends at column 0. `src/editor/ferrite/editor.rs:1127-1223`, `src/editor/ferrite/indent.rs:34-49`.
- **Outline unescape (#166):** positional escape restore desyncs when formatting-strip drops a masked escape (e.g. escaped char inside a link URL); literal U+E000 in a heading is eaten; `OutlineItem.id` hashes the title so collapsed-state keys change for previously-escaped headings. `src/editor/outline.rs:822`.
- **Stats (#171 residue):** `count_links` mixes byte and char indices — images after multi-byte chars get counted as links (miscount, not panic). `src/editor/stats.rs:369`.
- **Rendered view:** failed image loads re-read/re-decode/re-warn every frame (needs backoff or mtime-keyed failure cache) (`src/markdown/editor.rs:7349-7371`); mermaid `last_error` cleared each frame by the last-good fallback render (`src/markdown/widgets.rs:5282-5296`); arrow-nav state keys are process-global, so two windows clobber each other's nav state (`src/markdown/editor.rs:741-751`).
- **Mermaid semantics:** `autonumber` is global last-wins, not positional (off-then-re-enable diverges from Mermaid.js); `autonumber`-prefixed participant names swallow message lines; u64 overflow panic in debug builds on absurd start values; two distinct bidirectional edges between the same pair dedup to one; bare `subgraph id Title` id change can orphan edges in existing documents (worth a CHANGELOG compatibility note). `src/markdown/mermaid/sequence.rs`, `flowchart/render/edges.rs:85-108`, `flowchart/parser.rs:366-371`.
- **Sequence/gantt/gitgraph parsed 2-3× per visible frame** in fit mode (no cache, unlike flowcharts). `src/markdown/widgets.rs:5275, 5708`.

## Low / polish (nits)

- Ribbon Reload hover text is hardcoded English while the label is localized (`src/ui/ribbon.rs`).
- Homegrown date math in image filenames can produce month 13 / day 31 (`src/app/file_ops.rs`).
- 4096-byte Apple Event buffer silently drops very long macOS paths — add a log (`src/platform/macos.rs:407-425`).
- Percent-decode has no raw-target fallback (`my%20photo.png` literal filenames can't resolve) (`src/path_utils.rs:273-298`).
- Path traversal outside the workspace is allowed by design — document the stance rather than change it (`src/path_utils.rs`).
- `named_entity_map()` rebuilds a HashMap per call, per node, per frame; numeric entities decode to control chars — clamp per HTML spec (`src/markdown/html_entities.rs`).
- `ast_ops.rs`/`editor.rs` update helpers detect EOL from content (platform default on single-line docs) instead of `tab.line_ending` — first structural edit on a trimmed LF file can introduce CRLF on Windows.
- Mermaid: near-touch overlap pass can nudge nodes −0.01 px (missing `.max(0.0)`); test-only autonumber helpers not `#[cfg(test)]`-gated; stale module doc shows old 4-arg signature.
- `VIDEO_REPAINT_CTX` OnceLock pins the first egui Context forever (secondary-viewport risk); pre-existing lowercase-offset misalignment in find-replace fallback search.
- `indent_line` is production-dead (tests only); `unescape_backslashes` likewise.
