# v0.3.1 Quick Manual Test — ~30 minutes, Windows, real keyboard

**Why this list exists.** GrokBot ran the full suite on Linux twice (October: 198 rows,
ISS-1…63; November re-run of the fixes: 98 rows, ISS-64…75 — see `grokbot/README.md`),
with synthetic input on a virtual display. The round-3 fixes for ISS-64…75 are verified
only by unit tests. This is the shortest human pass that covers (a) the crash /
data-loss paths GrokBot found, (b) the things only a real keyboard and a real Windows
desktop can confirm, and (c) the headline 0.3.1 features. If you only have 10 minutes,
do **Part A** — rows **A1–A6** are the round-3 fixes (newest, unverified by a human),
**A7–A12** the earlier blockers.

> `[ ]` not run · `[x]` pass · write **FAIL** inline + add an `ISS-n` row at the end.
> Use a **release** build (`cargo build --release`; `panic = "abort"`, so any panic
> closes the app — that *is* the signal). Keep the debug log on
> (`ferrite --log-level debug`) so a FAIL has evidence.
> Longer lists if you have time: [`v0.3.1-minimal-release-test.md`](./v0.3.1-minimal-release-test.md)
> (~60 min) · [`v0.3.1-total-test.md`](./v0.3.1-total-test.md) (exhaustive).

## Part A — Must not break (≈12 min)

These are the GrokBot blockers. All are platform-independent except where noted.
**Linux-only, cannot be checked here:** ISS-66 (X11 `xclip` image paste — but do
**A6** with the Snipping Tool, it is the same code path on Windows) and ISS-69
(YouTube Error 153 from the `ferrite-video://` origin under WebKitGTK; Windows maps the
scheme to `https://ferrite-video.localhost`, so a Windows embed playing proves nothing
for Linux).

### Round 3 (ISS-64…75, fixed in `8c9c2d5`)

- [ ] **A1. Opening in Rendered never dirties or changes the file (ISS-68 / ISS-65 — blocker).**
  Open clean copies of `test_github_html.md` and `test_mermaid_issue_165.md` in Raw →
  note the status-bar char count → click **Rendered** → do nothing for 5 s → back to
  **Raw**. No `*` on the tab, char count identical (6376 for the #165 file), and the
  debug log has **no** `Content modified in rendered editor` line. Quit → no save prompt.

- [ ] **A2. Code-block edit touches only its block; one undo (ISS-65 — blocker).**
  `test_copy_and_split_undo.md` → **Split** → in the preview click at the end of the
  Python block, type `x` → Raw pane: only line 43 changed, line 49 still blank →
  **Ctrl+Z** once → file identical to the original (compare with `git diff`, must be
  empty) → Ctrl+Y → only `x` returns. Then in **Rendered** click into the same block
  and type `abcde` at normal speed → all five chars present → Ctrl+Z once → clean.
  A `Skipping heading commit:` WARN in the log is a FAIL even if the file looks right.

- [ ] **A3. Arrow keys walk blocks, including into a blockquote (ISS-64 — blocker).**
  `test_find_arrow_nav.md` → **Rendered** (padlock **off**) → click `## Section 1` →
  **ArrowDown** until the caret is in the Section 4 multi-line paragraph (15 block moves
  plus one press per extra wrapped row on the way — about 20 presses; the caret steps
  over the rust code fence) → type `X` → Raw: `X` is in the Section 4 multi-line
  paragraph (lines 49–52), heading untouched. The status bar `Ln` follows the caret
  (ISS-77). Then click the paragraph **before the blockquote** → ArrowDown →
  type `x` → Raw: `x` is inside the `> …` line. Also with preview lock **on**:
  ArrowDown / ArrowUp scroll the preview (no jump to the top, ISS-76), typing `Q`
  inserts nothing.

- [ ] **A4. Tab on a selection indents, never replaces (ISS-67 / T1-20).**
  `test_indent_selection.md` Raw → select **only the word** `alpha` on line 7 → **Tab**
  → the whole line 7 is indented one step, text intact → Ctrl+Z. Then select lines 7–9
  with Shift+ArrowDown, **Alt+click** line 33 to add a caret → Tab → lines 7–9 indented,
  line 33 gets the indent at the caret → **one** Ctrl+Z restores everything.

- [ ] **A5. Settings persist within a second, even on kill (ISS-74 / SI-4).**
  Settings › Editor › untick **Show Line Numbers** → keep moving the mouse over the
  window for 2 s → kill Ferrite from Task Manager (End task, not close) → open
  `config.json` → `"show_line_numbers": false`. Relaunch → line numbers off.

- [ ] **A6. Paste a screenshot with Ctrl+V (ISS-66 Windows half / #164).**
  Saved doc, caret at end of a line → **Win+Shift+S**, grab a region → **Ctrl+V** →
  `![](assets/….png)` inserted, PNG in `assets/`, image shows in Rendered. In an
  **Untitled** tab the same paste shows a "save the document first" toast. With
  `--log-level debug` the log shows `Smart paste: Saved clipboard image` — if instead
  it shows `Image paste: skipped, focus …`, that is the ISS-66 focus-guard branch: FAIL
  and attach the log.

- [ ] **A7. Config toast is visible and logged (ISS-72 / ISS-9).**
  Quit → `config.json`: `"font_size": "abc"` → launch → a **toast** ("1 setting reset")
  stays for ~30 s; log has `Config load toast:`. Other settings intact. Then replace the
  file with `{ not json` → launch → toast + `config.json.corrupt-…` next to it.
  Restore your config afterwards.

- [ ] **A8. Spell tooltip hides under the context menu (ISS-75 / SPL-3).**
  Spellcheck on → type `speling` → hover until the `Unknown word` tooltip shows →
  **right-click** the word → the tooltip is gone on the very first frame of the menu;
  the first suggestion row is fully readable. Bonus: `test_mermaid_v031.md` §3 Rendered →
  the fan-out edges are **curved** (ISS-73 fixture).

### Earlier blockers (rounds 1–2, re-verified in November except where noted)

- [ ] **A9. Typing a mermaid fence by hand (ISS-7 — real keyboard needed).**
  Ctrl+N → **Split** → type, character by character:
  ```` ```mermaid ```` Enter `flowchart TD` Enter `A[Start] --> B{Go}` Enter ```` ``` ````
  The opener stays exactly ```` ```mermaid ```` (no extra backticks, no reversed text);
  the diagram renders once the fence closes.

- [ ] **A10. Session restore then type (ISS-36 — seen once, possible data loss).**
  Open any saved multi-line `.md`, make sure **Restore previous session** is on, quit
  cleanly (Alt+F4), relaunch → the tab is back → click into it, **End**, type ` W1`
  → the text is **appended**; the rest of the document is still there; status bar
  word count is unchanged ±1. Ctrl+Z removes `W1` (the leading space may stay — word-
  granular undo, by design; SES-6).

- [ ] **A11. Rendered table edit reaches the file (ISS-41).**
  `test_tables.md` → **Rendered** → click a cell, type `X`, **do not** click another
  cell → switch to **Raw** (Ctrl+E) → `X` is there and the tab shows `*` → **Ctrl+S**
  → reopen the file in Notepad → `X` is on disk. Then `git checkout test_md/test_tables.md`.

- [ ] **A12. CRLF + UTF-16 survive (#174 / ISS-3).**
  Open `crlf-test.md` → Rendered → click "First paragraph.", type ` edited`, click
  away → Ctrl+S → CRLF check still `True`. Open `utf16.md` → it opens as **text in
  Ferrite** (not Notepad/other app) → Raw → Enter → Ctrl+S → `Format-Hex` shows only
  `0D 00 0A 00` pairs. (T1-4b: the UTF-16 text renders faint grey on Linux — note if
  it does on Windows too; cosmetic, 0.3.2.)

## Part B — New in 0.3.1 (≈20 min)

- [ ] **B1. Reload from Disk (#149).** Open a saved `.md`, edit it in Notepad, back in
  Ferrite **Ctrl+Shift+R** → content updates, no dialog. Type in Ferrite (dirty), edit
  in Notepad again, Ctrl+Shift+R → dialog; **Cancel** keeps your edit; **Don't Save**
  loads the disk version. Ctrl+Z once after reload → previous content comes back.

- [ ] **B2. Search in Files lands on the match (#178 / ISS-4).** Save a file in your
  workspace containing `搜索测试 中文 search` → **Ctrl+Shift+F** → query `中文` → click
  the result → caret is **on** `中文` (Ln 1, Col 6), highlight visible. Repeat with
  query `search` → caret at Col 11. Case-insensitive `istanbul` finds `İstanbul` (ISS-44).

- [ ] **B3. Paste a screenshot (#164 / ISS-5).** Covered by **A6**; here only the
  dual-format case: copy an image from a browser (right-click → Copy image) → Ctrl+V
  → the image is inserted (not the URL); copy a plain URL → Ctrl+V → smart-paste link.

- [ ] **B4. Spellcheck (#184).** Settings › Editor › **Spellcheck** on → Raw: type
  `This is a speling mistaek.` → both words squiggled within ~1 s → right-click
  `speling` → pick a suggestion → word replaced, **one** Ctrl+Z reverts it → **Add word to
  dictionary** on `mistaek` → squiggle gone, survives restart. **Alt+Z** (wrap on) →
  squiggles sit under the words, not at the right edge (ISS-48). Link text
  `[ok](http://speling.com)` → nothing in the link is flagged (ISS-47).

- [ ] **B5. Tab / Shift+Tab indent (#177 / ISS-51).** `test_indent_selection.md` Raw →
  select 3 lines → **Tab** → all indented, Ctrl+Z once reverts all → select Block 2
  (spaces + one hard-tab line) → **Shift+Tab** → every line outdents one step, including
  the tab line → caret alone on a line, Tab → inserts indent at caret only.

- [ ] **B6. Code blocks in Rendered (ISS-39 / ISS-40).** `test_copy_and_split_undo.md`
  → Rendered → Part A: mouse-select part of the Rust line, Ctrl+C, paste in Notepad →
  byte-identical, no spaces inserted after `.` / `(` / `<`. Part B Python block →
  **Edit** → Ctrl+End, Enter, type `alpha beta gamma` → **Done** → text is exactly as
  typed → **one** Ctrl+Z removes the whole added line. Don't save.

- [ ] **B7. Links in Rendered lists (ISS-42).** `test_local_links.md` Rendered →
  **Ctrl+click** a file link inside a list item → Explorer reveals it; Ctrl+click a web
  link → browser; **plain click** on the same item → enters edit mode, no freeze.

- [ ] **B8. Settings (search-first redesign).** **Ctrl+,** opens Settings → type `zoom`
  → Font Size row; **Esc** clears, **Esc** again closes the tab (ISS-12). Change theme
  + font size → close/reopen → **Recently changed** lists both; restart → still listed.
  **Reset All** asks for confirmation (ISS-17). First keystroke in the search box is
  not dropped (ISS-18 — real keyboard).

- [ ] **B9. System title bar still reachable (ISS-37).** Settings › Appearance ›
  **Use system title bar** on → restart → native title bar; **Ctrl+,** opens Settings
  and a gear is on the ribbon → turn the option off again → restart.

- [ ] **B10. Fonts (#176 / #185).** Settings › Appearance › **Rendered view font** →
  pick a different family → Rendered text changes, Raw text does not. Settings ›
  Terminal › font → open the terminal (Ctrl+`) → prompt uses the new font; glyphs are
  not clipped at cell edges.

- [ ] **B11. Single instance (#186).** With Ferrite running, double-click a `.md` in
  Explorer → opens as a tab in the **existing** window, window comes to front. From a
  terminal in another folder: `ferrite .\some.md` → relative path resolves against the
  terminal's folder, second process exits in ≲1 s. Settings › **Allow multiple Ferrite
  windows/instances** on → launching again opens a second, independent process; turn it off.

- [ ] **B12. Exit → Save with an Untitled tab (ISS-38 / ISS-63).** Two saved tabs +
  one Ctrl+N tab, type in all three → Alt+F4 → dialog **names the files**; with Quick
  note workflow **off** the Untitled tab gets a Save As; with it **on** the dialog says
  the untitled note is kept for next launch, and it is restored after relaunch.

- [ ] **B13. Closing a second window (QA SES-3).** Quick note workflow **on**.
  **Ctrl+Shift+N** → **Alt+F4** on the new, untouched window → it closes at once (it
  used to ignore Alt+F4). **Ctrl+Shift+N** again → type `abc` in its Untitled tab →
  **×** → Unsaved Changes dialog names the Untitled tab and does **not** say the note is
  kept for next launch → **Cancel** → window still there → **Alt+F4** → same dialog →
  **Don't Save** → window closes, the first window is untouched. Repeat once with
  **Save** → Save As appears, and the window closes after saving.
