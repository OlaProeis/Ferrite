# v0.3.1 Leftover Closeout — Manual QA Checklist

Pre-tag / post-cyclopsctl QA for the **Leftover Bug Fix & Editor Closeout** queue
(`031-prd.md`, tag `ferrite-v0-3-1-leftover-bug-fix-editor-closeout`).

All parent tasks in that tag are **done in code**. This document is the human
pass: open a release build of `0.3.1-experimental`, work top to bottom, tick each
box, and log every defect in **Issues Found**.

> **Scope:** Only the leftover closeout issues (#171, #174, #173, #175, #170,
> #149, #177, #168, #164, #154). For Mermaid / video / multi-window / earlier
> 0.3.1 pillars, use [`v0.3.1-test-checklist.md`](./v0.3.1-test-checklist.md).

## How to use

- `[ ]` not yet run · `[x]` pass · mark **FAIL** inline and add an `ISS-n` row.
- **Rendered** = preview only · **Split** = raw + preview · **Raw** = editor only.
- Primary platform: **Windows**. Rows tagged `(macOS)` / `(Linux)` need that OS.
- Prefer a **release** build (`cargo build --release` then run the binary).

### Pre-flight

- [ ] `cargo test` — **0 failed**
- [ ] `cargo build --release` — succeeds
- [ ] App launches; you are on branch / build that includes the leftover closeout

### Fixtures / prep

| Need | How |
|------|-----|
| HTML entities | Open [`test_md/test_html_entities.md`](../../../test_md/test_html_entities.md) |

| macOS Open With | `.md` associated with Ferrite (or Open With → Ferrite) |

## 2. Line endings CRLF / LF — `EOL` (#174)

Docs: [`line-ending-preservation.md`](../files/line-ending-preservation.md)

### CRLF (Windows)

- [ ] **EOL-1** Open a **CRLF** `.md` → switch to Rendered → **click a heading** (no real text edit) → tab is **not** dirty (or, if click-to-edit focuses, Escape without changing text leaves clean). Goal: EOL alone must not mark modified.
- [ ] **EOL-2** On that CRLF file, make a small Rendered edit (e.g. change one word) → Save → reopen in a hex/diff tool or `Format-Hex` / Beyond Compare → file still uses **`\r\n`** (not converted to LF-only).
- [ ] **EOL-3** Same file in **Split**: edit in preview, save → CRLF preserved.
- [ ] **EOL-4** Raw mode edit + save on CRLF file → CRLF preserved.

### LF

- [ ] **EOL-5** Open an **LF** `.md` → edit in Rendered → Save → still **LF** (`\n` only).

### Mixed (policy check)

- [ ] **EOL-6** `(optional)` Mixed EOL file → after save, one consistent ending is used (majority/first); no crash. Perfect per-line mixed rewrite is **out of scope**.

## 4. Find in Rendered / Split — `FIND` (#175)

Docs: [`find-in-rendered.md`](../editor/find-in-rendered.md)

Use a document with the same word appearing several times (scattered vertically so you must scroll).

- [ ] **FIND-1** **Rendered** → Ctrl+F → type a query with multiple matches → **Enter** or **F3** → viewport **scrolls** so the current match is visible; highlight advances.
- [ ] **FIND-2** Find previous (Shift+F3 or UI) also scrolls to the match.
- [ ] **FIND-3** **Split**: with focus such that Find targets the doc, next/prev scrolls the **preview** to the match (raw find scroll still works when searching in raw).
- [ ] **FIND-4** Ctrl+F when a previous query exists → query text is **selected** (typing replaces it; does not append).
- [ ] **FIND-5** **Raw** find next/prev still scrolls as before (no regression).

## 5. Arrow navigation in Rendered — `ARR` (#170)

Docs: [`rendered-arrow-navigation.md`](../markdown/rendered-arrow-navigation.md)

- [ ] **ARR-1** **Rendered** → click a paragraph → **ArrowDown** moves to the next navigable block; **ArrowUp** to the previous (not stuck on one line).

- [ ] **ARR-4** **Split**: arrows in the **raw** pane still move by line as before; arrows in the **preview** navigate blocks.
- [ ] **ARR-5** **Raw**-only mode arrows unchanged.

## 6. Reload from Disk — `RLD` (#149)

Docs: [`reload-from-disk.md`](../files/reload-from-disk.md)

- [ ] **RLD-1** Open a saved file → edit it in **Notepad** and save → back in Ferrite (clean tab) → **Ctrl+Shift+R** (or palette **Reload from Disk**) → content updates to disk; toast/success.
- [ ] **RLD-2** Dirty tab → Reload → **confirm** dialog appears → **Don't Save** reloads and discards; **Cancel** keeps edits.
- [ ] **RLD-3** Dirty tab → Reload → **Save** then reloads (or save-then-reload path as designed).
- [ ] **RLD-4** Untitled tab → Reload → toast that there is nothing to reload (no crash).
- [ ] **RLD-5** Ribbon Save dropdown → **Reload from Disk** works the same as the shortcut.
- [ ] **RLD-6** `(optional)` Settings → Keyboard → **Reload** is listed and rebindable.

## 9. Local images + clipboard paste — `IMG` (#164)

Docs: [`local-image-assets.md`](../markdown/local-image-assets.md), [`clipboard-image-paste.md`](../markdown/clipboard-image-paste.md)

Use a **saved** `.md` (path on disk) so `assets/` can be created beside the file.

### Drag-drop

- [ ] **IMG-1** Drag a PNG onto the editor → file appears under `./assets/` next to the markdown → source has `![](assets/…)` → **Rendered shows the image** (not “Image not found”).
- [ ] **IMG-2** Paths like `![](./assets/foo.png)` or MarkText-style variants still resolve if present.

### Clipboard

- [ ] **IMG-3** Copy an image to the clipboard (Snipping Tool / browser Copy image) → focus Raw → **Ctrl+V** → PNG under `assets/` + markdown insert → image visible in Rendered.
- [ ] **IMG-4** Undo once → markdown insert removed (file on disk may remain — note behaviour).
- [ ] **IMG-5** Paste normal **text** still pastes text (no false image insert).

### Remote (must stay local-first)

- [ ] **IMG-6** `![x](https://example.com/a.png)` does **not** fetch/render the remote image (placeholder / “Web images not supported” / link behaviour as designed).

### Preview lock

- [ ] **IMG-7** Preview locked → clipboard image paste into **raw** (Split left / Raw) still allowed; preview mutations stay gated.
