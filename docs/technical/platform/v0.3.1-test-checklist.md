# v0.3.1 Manual Test Checklist

Pre-tag manual QA for everything that landed on `0.3.1-experimental` (vs
`master`). Work top to bottom, tick each box, and log every defect in the
**Issues Found** table at the end — that table feeds the post-test PRD.

> **Scope:** v0.3.1 features and fixes only. Generic regression coverage lives in
> the [v0.3.0 regression matrix](./v0.3.0-regression-matrix.md). Run that first
> if you are also validating the platform stack.

## How to use

- `[ ]` not yet run · `[x]` pass · mark **FAIL** inline and add an `ISS-n` row.
- "Rendered" = preview-only view; "Split" = raw + preview; "Raw" = editor only.
- Primary platform is **Windows** (most v0.3.1 fixes are Windows-specific);
  cross-platform rows are flagged `(Linux)` / `(macOS)`.

### Pre-flight

- [x] `cargo build --release` completes with **zero errors**.
- [x] `cargo test` reports **0 failed**.
- [x] `cargo check` warning count noted (v0.3.1 currently has known dead-code
      warnings — see ROADMAP pre-tag list; confirm no *new* ones from your build).
- [x] App launches to Welcome within ~3s; version string shown.
